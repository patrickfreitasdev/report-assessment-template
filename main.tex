\section{Introduction}

This section establishes the background, purpose, and scope of the sample
report. The organisation in this example operates a hybrid environment and
relies on a \gls{vpn} for remote staff access. First use of an acronym
expands automatically; later uses of \gls{vpn} remain abbreviated.

The purpose of this document is to demonstrate template features rather
than present a real assessment outcome.\footnote{Footnotes use hanging
indentation, increased separation from the body text, and a shortened
rule so long explanatory notes remain readable.}

Scope covers sample prose, lists, citations, tables, figures, code
blocks, prompt blocks, and appendices. Items outside scope include live
deployment data and organisation-specific credentials.

According to \citet{Kurose2021}, layered designs remain a practical way
to reason about interconnected systems. Parenthetical citations follow
Kaplan Harvard formatting \citep{Tanenbaum2021,NIST2020}.

Key observations from the fictional review:
\begin{itemize}[leftmargin=1.5em]

  \item Change records lacked a consistent link to configuration snapshots.
